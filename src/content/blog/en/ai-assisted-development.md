I use GitHub Copilot and Claude Code in my development work. My position is simple: AI tools speed up the work, but responsibility for the code stays with whoever ships it.

## Principles

- **Human review, always.** Any code suggested by an AI goes through the same review as any other code.
- **Tests and code review do not change.** The team's quality process applies equally to code written with or without assistance.
- **Understand before accepting.** If I cannot explain what the code does, it does not go in.
- **Mind sensitive information.** Confidential code and data from an employer or clients should not be shared with tools that are not approved for it.

This post is short on purpose: it describes principles, not results. When I have concrete experiences I can share publicly, they will go into new articles.
