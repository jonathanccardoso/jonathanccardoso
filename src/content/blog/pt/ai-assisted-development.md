Uso GitHub Copilot e Claude Code no desenvolvimento. Minha posição é simples: ferramentas de IA aceleram o trabalho, mas a responsabilidade pelo código continua sendo de quem o entrega.

## Princípios

- **Revisão humana sempre.** Todo código sugerido por uma IA passa pela mesma revisão que qualquer outro código.
- **Testes e code review não mudam.** O processo de qualidade da equipe vale igualmente para código escrito com ou sem assistência.
- **Entender antes de aceitar.** Se não consigo explicar o que o código faz, ele não entra.
- **Cuidado com informações sensíveis.** Código e dados confidenciais do empregador ou de clientes não devem ser compartilhados com ferramentas que não estejam autorizadas para isso.
